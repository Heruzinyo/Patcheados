Pegue esta fonte [AQUI](https://drive.google.com/uc?id=1PyCbHexus84IipG4bQjQ088VT4YhKOmw&export=download) e instale-a no Windows (copie para C:\Windows\Fonts).

Se depois de instalar o patch, o executável `SiglusEngine.exe` travar, tente substituí-lo com este `.exe` [AQUI](https://drive.google.com/uc?id=1bkYzv-V4toXgmuup_o6aXhYczzZ2GOzj&export=download).
